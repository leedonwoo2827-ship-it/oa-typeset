# HTML 작성 규칙

조판기(html2hwpx · docx · deck13)가 옮기는 태그만 씁니다. 이 규칙은 사람이 쓸 때도, LLM 에게 시킬 때도 같습니다.
LLM 프롬프트에 들어가는 원문은 [`oa_typeset/writer.py`](../oa_typeset/writer.py) 의 `HTML_RULES` 입니다.

## 뼈대

```html
<!doctype html>
<html lang="ko">
<head>
<meta charset="utf-8">
<title>문서 제목</title>          <!-- 한글 바탕쪽 머리말에 들어간다 -->
</head>
<body>
<h1>문서 제목</h1>
<p><small>부제·안내 한 줄</small></p>

<h1 style="break-before:page">1장. …</h1>
<h2>1. …</h2>
<p>본문 …</p>
…
</body>
</html>
```

`<head>` 의 `<style>` 은 브라우저 미리보기용입니다. 조판에는 `break-before:page` 규칙만 쓰입니다.

## 태그별

| 쓰는 것 | 뜻 | 메모 |
|---|---|---|
| `<h1>` | 장 | 새 쪽에서 시작하려면 `style="break-before:page"` |
| `<h2>` `<h3>` `<h4>` | 절 · 항 · 세부 | 번호(1. / (1) / 1))는 **글에 직접** 쓴다 |
| `<p>` | 본문 문단 | 한 문단 = 한 생각. 너무 길면 나눈다 |
| `<b>` | 굵게 | 핵심어만. `<strong>` 도 된다 |
| `<small>` | 작은 회색 글씨 | 주석·출처·그림 제안 |
| `<ul><li>` · `<ol><li>` | 목록 | 글머리 기호·번호는 **자동**. 직접 `•` `1.` 을 쓰면 그대로 둔다(겹치지 않음) |
| `<table>` | 표 | 머리 칸은 `<th>`. 가로 병합 `colspan` 만. **세로 병합(rowspan)은 쓰지 않는다** |
| `<img src="상대경로" style="width:120mm">` | 그림 | png · jpg · gif · bmp · svg. 폭을 안 주면 원본 크기(본문 폭 80% 안) |
| `<pre>` | 코드·고정 폭 | 줄마다 한 문단 |
| `<blockquote>` | 인용 | 들여쓴 문단 |

## 쓰지 않는 것

- `<div>`·`<span>` 으로 꾸미기, `class`·인라인 색·글꼴 지정 — 서식은 양식이 정합니다.
- `<br>` 여러 개로 줄 띄우기 — 문단 간격은 양식의 문단 모양이 정합니다.
- 마크다운 기호(`**`, `##`) — HTML 안에서는 글자 그대로 찍힙니다.
- 외부 그림 주소(`http://…`) — 내려받지 않습니다. 파일로 옆에 둡니다.

## 그림

- SVG 를 쓰면 Edge/Chrome 헤드리스로 PNG 를 구워 넣습니다. 옆에 같은 이름의 `.png` 가 있으면 그것을 씁니다.
- LLM 집필에서는 그림 자리에 `<p><small>[그림 제안: …]</small></p>` 만 남기게 합니다. 사람이 그리거나 따로 SVG 를 요청합니다.

## 분량 어림

양식의 `form.json` 에 `chars_per_page` 가 있습니다(교재형 1,100자, 보고서형 1,300자). 표·그림이 많으면 쪽당 글자는 줄어듭니다.
정확한 쪽수는 `--finish` 로 한글이 실제로 앉힌 뒤의 `pages` 값을 봅니다.
