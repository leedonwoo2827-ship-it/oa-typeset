# 젠오피스 연동 메모

젠오피스에서 요약집·교재를 만들 때 **"LLM 이 한글 문서를 직접 만들게"** 하던 단계를 **"LLM 은 HTML 까지, 조판은 oa-typeset"** 으로 나누자는 제안입니다.

## 지금과 바꾼 뒤

```
지금   : 자료 ──LLM──▶ hwpx (서식까지 LLM 이)              → 스타일 1개, 바탕쪽 없음
바꾼 뒤 : 자료 ──LLM──▶ HTML ──oa-typeset + 회사 양식──▶ hwpx/docx/pptx
                         (글만)      (서식은 양식이)
```

- LLM 은 **글과 구조**(제목 단계·목록·표)만 책임집니다. HTML 은 LLM 이 가장 안정적으로 쓰는 형식입니다.
- 서식은 **회사 양식 파일**이 책임집니다. 양식을 바꾸면 같은 원고가 다른 모양으로 나옵니다.
- 원고(HTML)가 남으므로 같은 내용으로 hwpx·docx·pptx 를 다 뽑을 수 있고, 고칠 때도 HTML 만 고칩니다.

## 붙이는 순서 (제안)

1. 젠오피스 서버 PC 에 설치합니다: `pip install "oa-typeset[office] @ git+https://github.com/leedonwoo2827-ship-it/oa-typeset"`
2. 젠오피스의 LLM 프롬프트 끝에 [HTML 작성 규칙](HTML_작성규칙.md) 을 붙이고, 출력을 `.html` 로 받습니다.
   - 규칙 원문은 `from oa_typeset.writer import HTML_RULES` 로 가져다 쓸 수 있습니다.
   - 70쪽 분량이면 한 번에 쓰게 하지 말고 **장별로** 나눠 받습니다(`writer.write_book` 이 하는 방식).
3. 회사 양식을 `forms/<이름>/` 에 넣습니다([양식 만들기](양식_만들기.md)).
4. 조판을 부릅니다. README §3 의 세 방법 중 하나를 씁니다.
   - Python: `typeset(html, form, formats, out_dir)`
   - CLI: `oa-typeset --json build …`
   - HTTP: `POST /api/typeset`
5. (선택) 서버에 한글·PowerPoint 가 있으면 `finish=True` 로 쪽수·PDF·끝줄 정리까지 받습니다.

## 확인할 것

- 결과 JSON 의 `notes` 에 경고가 옵니다. 예: 그림을 못 구움, 슬라이드가 넘침, 한글 마무리 실패.
- `hwpx.tables` / `hwpx.images` 개수를 원고와 비교하면 빠진 것이 있는지 바로 압니다.
- 한글 자동화를 처음 돌리면 "접근 허용" 창이 뜹니다. **[모두 허용]** 을 누르거나 README §6 대로 보안 모듈을 등록합니다.
