# 양식 만들기

양식 하나 = `forms/<이름>/` 폴더 하나입니다. 세 파일 중 있는 것만 씁니다.

| 파일 | 엔진이 가져가는 것 | 가져가지 않는 것 |
|---|---|---|
| `form.hwpx` | 글꼴, **문단 스타일**, 글자·문단 모양, 쪽 설정(판형·여백), **바탕쪽**(머리말·꼬리말·쪽 테두리·쪽 번호) | 본문 글, 표지, 둘째 구역부터 |
| `form.docx` | 명명 스타일(Title · Heading 1~3 · Normal · List Bullet · Quote), 쪽 설정, 머리글·바닥글 | 본문 글 |
| `form.pptx` | 배색 15색(마지막 '배색' 장의 `pal:*` 사각형), 가장 많이 쓴 글꼴, 임베드 글꼴 | 슬라이드 배치·좌표(엔진 고정) |
| `form.json` | 이름·설명·판형·HTML↔스타일 짝·집필 지침 | — |
| `logo_left.png` `logo_right.png` | 슬라이드 좌상단·우상단 로고 (있을 때만) | — |

## hwpx 양식 — 순서

1. **한글에서 양식을 HWPX 로 저장합니다.** `.hwp` 는 바로 쓸 수 없습니다(다른 이름으로 저장 → 파일 형식 HWPX).
2. **스타일 이름을 확인합니다.** 한글의 스타일(F6) 목록이 그대로 나옵니다.
   ```bat
   oa-typeset styles 회사양식.hwpx
   ```
   ```json
   {"styles": ["바탕글", "본문", "제목 1", "제목 2", "제목 3", "표내용", …],
    "suggest": {"body": "본문", "h1": "제목 1", "h2": "제목 2", "h3": "제목 3", "cell": "표내용"}}
   ```
3. **빈 양식으로 정리합니다.** 본문·표지·다른 구역·본문 그림을 지우고, 바탕쪽 글자는 '머리말'로 바꿉니다(문서마다 HTML `<title>` 로 다시 채움). 남에게 주거나 공개 레포에 올릴 때는 꼭 합니다.
   ```bat
   python -m oa_typeset.formkit.clean_form 회사양식.hwpx forms\우리회사\form.hwpx
   :: 표지 구역 뒤의 본문 구역에서 쪽 설정을 가져오려면 --section 1
   ```
4. **`form.json`** 을 씁니다. `styles` 에는 2번의 `suggest` 를 넣고, 빠진 짝을 채웁니다.
   ```json
   {
     "title": "우리회사 보고서",
     "description": "A4 세로, 개조식 보고서",
     "page": "keep",
     "styles": {"body": "본문", "h1": "제목 1", "h2": "제목 2", "h3": "제목 3", "h4": "제목 3", "cell": "표내용"},
     "pages_target": 30,
     "chars_per_page": 1300,
     "guide": ["개조식(~함)으로", "h1 = Ⅰ. Ⅱ. 대목차", "수치는 표로"]
   }
   ```
   - `page`: `"keep"` 이면 양식 판형 그대로, `"210x297"` 처럼 mm 를 주면 그 판형으로 바꿉니다.
   - `styles` 의 키: `body` `h1` `h2` `h3` `h4` `cell`(표 칸). 양식에 없는 이름은 기본 모양으로 나갑니다.
   - `guide` 는 LLM 집필 때 프롬프트에 들어갑니다(문체·번호 체계·표 기준).
5. 견본으로 확인합니다.
   ```bat
   oa-typeset build samples\요약집-예시.html --form 우리회사 -f hwpx --finish
   ```

## docx 양식

회사 Word 양식이 있으면 그대로 `form.docx` 로 둡니다. 없으면 판형·글꼴만 정한 기본 양식을 만듭니다.

```bat
python -m oa_typeset.formkit.make_docx_form forms\우리회사\form.docx --page 210x297 --margin 20 --font "맑은 고딕" --size 11
```

## pptx 시안

`form.pptx` 는 '양식'이 아니라 **시안**입니다. 엔진은 시안에서 **색과 글꼴만** 읽고, 슬라이드는 13종 레이아웃 엔진이 직접 그립니다.

- 색을 바꾸려면 시안 마지막 장('배색')의 사각형 채움색을 바꿉니다. 사각형 이름이 `pal:navy`(주색), `pal:amber`(강조색), `pal:navy_55`(옅은 주색), `pal:chip`(아주 옅은 면) 입니다.
- 시안을 새로 그리려면 `python tools/build_pptx_template.py --sample <색을 바꾼 시안> --out forms\우리회사\form.pptx` 를 실행합니다. 로고를 넣으려면 환경변수 `OA_LOGO_RIGHT`·`OA_LOGO_LEFT` 에 png 경로를 줍니다.
